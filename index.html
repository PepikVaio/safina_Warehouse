PŘIPOJENÍ A UŽIVATEL

Nastavení

Nástroje správce jsou určeny pouze pro správce skladu.

SPRÁVA PŘÍSTUPŮ

Uživatelé

Přístupové tokeny se ukládají pouze jako SHA-256 otisky. Samotný token se do users.json neukládá.

Přidat uživatele

Token vytvoří správce pod účtem PepikVaio. Pro role Write a Admin musí mít token Contents: Read and write.

Pozvánka je připravena. Odkaz obsahuje přístupový token. Posílej ho pouze soukromě; kdokoli, kdo získá odkaz, může token použít.

POZVÁNKA DO SKLADU

Nastavení přístupu

Odkaz obsahuje přístupový token. Na této stránce ho nezobrazujeme. Po uložení bude bezpečně uložen v tomto prohlížeči.
